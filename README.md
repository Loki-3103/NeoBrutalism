## Features

This portfolio is designed as a single-page experience inspired by Neo-Brutalist desktop applications and retro browser windows. The interface functions like an open software application, allowing visitors to navigate seamlessly through different sections without leaving the main window.

The portfolio includes dedicated sections for Home, Timeline, Projects, Skills, Leadership, Beyond Code, and Contact. A chronological timeline presents my journey from 2023 to the present, highlighting key milestones, achievements, and learning experiences.

Projects are displayed with direct links to both live deployments and GitHub repositories, enabling recruiters and developers to explore my work easily. The contact section includes an interactive popup with quick access to my email and LinkedIn profile.

To enhance the experience, the background features a dynamic grid that reacts to cursor movement by filling with color and gradually fading away. Every button and interactive card uses a Neo-Brutalist push-button effect to create a tactile and engaging interface. The entire website is fully responsive, adapting smoothly across desktop, tablet, and mobile devices with a dedicated bottom navigation bar for smaller screens.
